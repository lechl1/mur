// =========================================================== Description
== Description

// tag::body[]
{manpurpose}.
The element is either a window or an empty workspace.

mur keeps every focused window in a focus stack, most recent first.
`focus-back-and-forth` focuses the most recent window that still exists, other than the focused one,
on whichever workspace it is: after the focused window closes, that is the window focused before it,
and running it again flips back.
Minimized and hidden windows are skipped.
When there is no other window to go to, the command exits with a non-zero exit code,
so it may be combined with `workspace-back-and-forth`: +
----
mur focus-back-and-forth || mur workspace-back-and-forth
----

Also see: <<workspace-back-and-forth, workspace-back-and-forth>>
// end::body[]
